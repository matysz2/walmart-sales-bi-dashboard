# Walmart Sales BI Dashboard

This project presents an end-to-end sales analysis based on Walmart historical sales data.

The main goal of the project is to build a complete Business Intelligence solution using Microsoft SQL Server and Power BI. The project includes data validation, SQL analysis, data transformation, data modeling, DAX measures and the creation of an interactive sales dashboard.

## Business Goal

The purpose of the analysis is to:

- evaluate sales performance across stores,
- compare store types and store sizes,
- identify the highest-performing stores,
- analyze sales trends over time,
- compare holiday and non-holiday sales,
- create key performance indicators for business reporting.

## Data Sources

The project uses two CSV files:

- `Walmart_Sales.csv` — weekly sales data,
- `stores.csv` — store type and store size information.

The datasets are connected using the `Store` column in a one-to-many relationship.

## Project Workflow

1. Data validation in SQL Server
2. Duplicate and missing value checks
3. SQL queries for business analysis
4. Data import into Power BI
5. Data transformation in Power Query
6. Data model creation
7. DAX measure development
8. Dashboard design
9. Business conclusions and recommendations
